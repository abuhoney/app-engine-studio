🔐 Identity Studio (v6.0 NEW) — Dynamic Firebase Identity Shimming. Admin can change package name, project id, google-services.json values, and more — WITHOUT rebuilding the APK. Changes take effect on next app launch.
⚠️ Important: The real Android package name (com.allarab.services) cannot be changed post-install (Android OS limitation). However, you can change the virtual package name shown in the UI, and you CAN change all Firebase credentials (project ID, app ID, API key, database URL, storage bucket) which effectively switches the app to a different Firebase project.
ℹ️ How it works: The app fetches /config/app_identity from Firebase on launch. If the credentials there differ from the built-in ones, the app initializes a secondary FirebaseApp instance with the new credentials and uses it for all subsequent calls. The old credentials remain as fallback.
